Publish `create-cartwright` with npm build provenance: a SLSA attestation generated by the release workflow through GitHub OIDC, so the package page on npm shows that the published tarball was built from this repository by that workflow. A project that depends on the CLI can verify it with `npm audit signatures`. Nothing changes in the CLI itself. Tashan's independent index (2026-09-13) listed "no build provenance" as the package's primary weakness.
