`cartwright design install <slug>` now also brings the self-hosted font folders the design imports. A design such as `brutalist`, `editorial-ink` or `meridian` imports its fonts from `@/app/fonts/<family>/font`, a folder outside `designs/<slug>/`, so installing it into a project that lacked the folder (a `--profile site` scaffold, for one) left a design that would not build. The command now reads the pack's imports and fetches each `app/fonts/<family>/` from the same template ref as the pack, and prints which font folders it added. A folder you already have is never overwritten, even with `--force`: when it matches the template it is reported as already present, and when it differs it is kept and the output says so. An import path that leaves `app/fonts/<family>/`, such as `@/app/fonts/../../x`, is refused and named, never fetched. A design with no font imports installs exactly as before. Not covered: fonts a design loads in any other way than an import, such as a CSS `url()` to a file outside its folder.
