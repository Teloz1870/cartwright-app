`npx create-cartwright .` works. It used to refuse every directory that already existed, so scaffolding into the current folder failed even when that folder was empty. A folder that is empty, or holds only `.git`, `.gitignore`, `README.md` or `.DS_Store` (what `git init` or a fresh GitHub clone leaves), is now accepted; the template's own `.gitignore` and `README.md` replace those two, and the CLI says so. A folder with anything else in it is still refused, and the message lists what is in the way. Your home directory and the filesystem root are always refused. A folder that already has a git remote is no longer offered a new GitHub repository.

The project name now comes from the last segment of the path you pass, not from the whole path. `npx create-cartwright /tmp/cartwright-new --yes` used to write `storeName: "/tmp/cartwright New"` and a `storeSlug` with slashes into `brand.config.ts`; it now writes `Cartwright New` and `cartwright-new`. The name is made into a slug: spaces and capitals are folded, and æ, ø and å become ae, oe and aa rather than being dropped. A folder called `tmp`, `home` or the same as your user name gets the default `my-cartwright-shop` instead. The "Next steps" lines now print the path to `cd` into, which is the path you passed, or `.`.
